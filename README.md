# Klox CDN

This repository contains CDN assets for [Klox](https://klox.ai/), an AI-powered
visual storytelling platform.

Klox helps creators turn ideas, scripts, and storyboards into videos with an
AI-assisted creative workflow. It is designed to support a range of visual
styles, from cinematic 3D and live-action concepts to animated and painterly
shorts.
